# 参考图精准复刻：视觉、复用、可编辑性与验收

适用于用户指定为最终依据的页面图片，以及生成/美化流程中已确认参考页的可编辑制作阶段。目标是 **1:1 还原视觉，背景之外的大部分内容组件可原生编辑**。本规范细化当前路线，不重新选择风格、安装模板或增加一轮设计确认；已有参考选择与用户委托按原流程记录。

## 1. 视觉还原与有限协调

- **依据优先级**：用户本轮的具体要求 → 已确认参考图及批准的修改 → 可核对的源材料。源 PPTX、PDF 和素材库提供文字、数据与组件证据，不取代参考图的布局和样式。逐页保持可见内容、标点、数值、公式、换行、字体层级、配色、几何比例、裁剪、间距与图层关系；不因易于实现而删减、概括或更换构图。
- **画布**：遵从用户指定的画布；未指定时以参考画面为依据，不强套源 PPTX 或常见的 16:9。轻微裁剪比例差异可等比放置并补最少量同色背景，记录处理方式；明显混合比例需要确定统一处理方案，不能拉伸或静默裁掉内容。
- **生成页不协调时**：先核对字体、文本度量、对象变换和裁剪，修复还原错误。实际 PPTX 仍有非刻意的文字溢出、遮挡、局部比例失衡或留白明显不均时，可对相关对象的字号、行距、框尺寸、间距和位置作最小调整，保持原文、数据、语义关系、主要构图与视觉重点。记录页码、对象、调整前后及原因；这类局部协调不另开设计确认。
- **调整边界**：用户要求严格像素复刻、禁止调整，或页面用于展示排版反例/刻意失衡时，保留指定原貌。改变主要构图、内容取舍、表达方式或图表类型属于重新设计，按已有确认流程处理；不能用“协调”扩大授权。

## 2. 复用原 PPT 与技能内置组件

先查看与当前页面相关的候选及其实际外观，再决定复用；不遍历整套素材库。优先顺序是匹配的源 PPTX 原生组件 → 技能内匹配的原生/矢量组件 → 按参考重建。只采用能保持参考身份、结构和几何关系的组件，不为复用而替换成近似图标或套用另一套视觉风格。

| 来源 | 复用方式与边界 |
|---|---|
| 用户提供的 PPTX | 检查具体幻灯片、对象及组合。优先保留文本 run、原生形状、连接关系、分组、图片裁剪，以及表格单元格或图表数据；仅按参考调整必要属性。复制后的主题继承、字体、组合缩放和资源关系必须在目标文件中复核。 |
| 技能内置素材 | 从 [资源入口](../assets/templates/README.md) 定向定位图标、[图表索引](../assets/templates/charts/charts_index.json)、[表格索引](../assets/templates/tables/tables_index.json)、[正面教材](positive-examples.md)或原型中的局部组件，并实际查看候选。按参考适配尺寸、颜色、线条与标签；引用组件不等于安装 Brand/Style/Layout/Deck，也不改变当前路线。 |
| 无合适实现 | 用当前原生后端按参考重建。可编辑组件不得为省事改成截图；复杂原图按下一节的图片例外处理。 |

在既有页级映射或资源记录中保留：目标页/区域、来源文件、源页与对象标识或素材路径、实际复用方式、目标对象类型，以及必要的适配。区分“看过作为参考”“已复用原生对象”“保留独立图片”；有映射或复制成功不等于视觉与可编辑性已验收。保留已有素材的来源和署名。

## 3. 背景之外主要组件可编辑

“可编辑”按内容类型判断，不能用大量无意义小形状或切碎图片凑对象数。主要文字、结构和可靠数据应落实为原生对象；照片与复杂原图的合理例外逐项说明。

| 组件 | 默认实现与验收边界 |
|---|---|
| 标题、正文、列表、图注和独立标签 | 原生文本框、段落与 run；内容、换行、强调和字体实际显示可核对。将字转轮廓或在截图上放透明文字不算文本可编辑。 |
| 框、分隔线、简单图标、几何示意和流程关系 | 独立原生形状、连接线或受支持的原生自由形状；可按语义分组并取消分组。转换矢量后应验证目标对象，不能仅因来源是 SVG/EMF 就宣称内部可编辑。 |
| 可核实数值的图表与可读表格 | 优先复用或生成原生 Chart 与数据、原生表格单元格。使用本包原生数据接口时遵从 [native-data-interface.md](native-data-interface.md)，启用 `--native-charts-and-tables`；核对值、标签、单位、坐标关系及缓存/工作簿。不能从 AI 设计图反推出实测数据。 |
| 公式 | 优先 Office Math；超出支持范围时保留精确原图并列明限制，不改变公式含义或伪造可编辑性。 |
| 照片、复杂插画、论文原图与无法可靠原生化的复杂证据图 | 保留为独立图片对象，能移动、缩放和裁剪；图外标题和独立标签仍应原生化。图内不可分的文字、曲线和细节明确列入图片例外，不宣称内部语义可编辑。 |
| 背景 | 可为背景填充或独立底层位图，仅含真实背景和装饰；不烘焙本应独立的文字、表格、流程结构或数据标签。 |

禁止整页截图加少量可编辑覆盖物、隐藏整页参考图作底板，或把截图分成小块冒充组件重建。不能因复杂图允许保留图片，就把主要正文、易读表格或简单流程整体扁平化。若例外使“主要内容可编辑”的目标无法满足，应报告具体受影响区域和可行替代，不能以图片移动能力代替语义编辑能力。

对不清晰的文字、数值或公式，先核对源文件和可靠独立素材，不猜测或生成补写。未解决区域单独记录，并继续不依赖它的工作；包含未解决证据的页面不宣称已验收。

## 4. 视觉与可编辑性分别验收

两项验收都针对**实际导出的 PPTX**，不以 SVG 预览、文件存在、退出码或单个相似度分数代替。

| 验收项 | 证据 |
|---|---|
| 页面覆盖 | 回读实际文件的页数、自然数字顺序、画布及参考页映射；不静默增删页。 |
| 视觉还原 | 在可用的真实 PPTX 渲染器中渲染全部输出页，优先使用目标 PowerPoint。与参考图等比对齐并逐页并排查看；必要时增加半透明叠加或差分，定位标题、框角、表格边界、箭头端点、换行、裁剪和遮挡的偏差。不能对成品作局部拉伸来掩盖差异。 |
| 原生对象 | 回读文本、形状/分组、连接线、表格、图表与数据、公式及图片类型，核对主要内容确实原生化。检查完整参考截图未被重新编码或分块作为成品底板；只查媒体哈希或统计形状数均不足。 |
| 编辑抽查 | 对实际使用的主要对象类型作代表性编辑检查，例如修改文本/单元格、修改图表数据或移动一个组合组件。在目标应用可用时用副本验证编辑与重新显示；仅做包结构检查时明确其范围，不写成目标软件编辑通过。 |
| 复用与例外 | 核对实际采用的组件来源映射、图片保留区域、局部协调记录和剩余偏差；确认复用后没有字体替换、裁剪漂移或主题污染。 |

用户给定误差容限时按其验收；未给定时不宣称“像素完全一致”或编造统一相似度合格线。局部协调在对照图和记录中明确标识，不作为无说明的还原偏差。发现问题先修复所属原生对象/资源，再重新导出并复查受影响页面；沿用当前路线的重试与停止条件，不无限修复。

交付 PPTX、真实逐页渲染与参考对照，并在既有验收记录中简述每页视觉结果、原生编辑范围、组件来源、图片例外、协调调整及未解决项。区分自动结构检查、目视复核、目标软件打开与实际编辑；未执行的项目写“未验证”。
