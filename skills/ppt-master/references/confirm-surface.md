# Chat Confirmation Surface

Perform all confirmation in chat. User
replies, inline page images and the cumulative agreed design are authoritative.

## Stage 1 — communication and template choice

Retain audience, language, intent, audience outcome, core message, context,
afterlife, content-divergence, canvas and page-count constraints from the real
request. Ask only unresolved material choices. Present the framework and exact
template roots when used; the ordinary academic recommendation is the bundled
academic-research method with light swiss-minimal visuals. Do not assert that a
Style-only workspace supplies slide prototypes. Install selected roots only
after confirmation; free design requires no fake installer receipt.

## Stage 2 — complete design direction

Discuss the whole solution, narrative outline, color and typography hierarchy,
image jobs, notes/animation/audio defaults, generation mode and spec depth in
chat. Prefer host-native AI generation. Use an external API only after the user
has selected and configured it; record the actual acquisition path. Keep settled choices and allow free-form
revision. The normal Design Spec/lock schemas still carry the resulting values;
Keep settled decisions in the project plan and reference-review records.
Derived template selection metadata is not a separate human submission.

## Per-page visual approval

Strategy approval is not approval of unseen slides. Follow
[academic-chat-design.md](academic-chat-design.md) §5: show every actual reference
image with page ID/revision, await explicit responses, and transcribe those
responses into reference_review decisions only afterwards. Silence is not
consent. User-provided approved images and explicit delegation carry their
actual scope; do not ask again or pretend the user saw an undisplayed image.

## Feedback and resume

Preserve the same plan and page IDs. Feedback may name a page, object or region.
Keep unchanged approvals, regenerate changed reference images and reconfirm
their current revision. On resume, read the source-bound manifest and real
decisions; image hashes prove which version was approved, not human identity.
